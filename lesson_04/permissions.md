# Права доступа проекта shop

## Команда и роли

| Роль | Учётная запись | Группы |
|------|----------------|--------|
| разработчик | alex | shop-dev |
| разработчица | bella | shop-dev |
| аналитик | chris | — (только личная) |
| администратор | root | sudo |

Маска **umask 0027** для команды: новые файлы получают `640` (`rw-r-----`), каталоги — `750` (`rwxr-x---`). Это закрывает проект от остальных пользователей системы.

---

## Каталоги

### 1. `/srv/shop/src`

- **Владелец:** root
- **Группа:** shop-dev
- **Права буквами:** `drwxrws---`
- **Права числом:** `2770`
- **Почему так:** разработчики пишут код, аналитик к коду доступа не имеет; setgid гарантирует, что новые файлы получат группу `shop-dev`, а не личную группу создателя.

### 2. `/srv/shop/releases`

- **Владелец:** root
- **Группа:** shop-dev
- **Права буквами:** `drwxrwsr-x`
- **Права числом:** `2775`
- **Почему так:** разработчики публикуют сборки, аналитик и остальные читают, но не пишут; setgid сохраняет группу `shop-dev` для новых файлов.

### 3. `/srv/shop/uploads`

- **Владелец:** root
- **Группа:** shop-dev
- **Права буквами:** `drwxrws--T`
- **Права числом:** `3770`
- **Почему так:** общий каталог для загрузок; sticky-бит запрещает удалять чужие файлы, setgid сохраняет группу, для остальных доступа нет.

---

## Файлы

### 4. `/srv/shop/src/app.py` — общий код

- **Владелец:** alex
- **Группа:** shop-dev
- **Права буквами:** `-rw-rw-r--`
- **Права числом:** `664`
- **Почему так:** группа `shop-dev` пишет (bella дописывает строки), остальные только читают.

### 5. `/srv/shop/src/config.env` — секрет

- **Владелец:** alex
- **Группа:** shop-dev
- **Права буквами:** `-rw-------`
- **Права числом:** `600`
- **Почему так:** токен доступа не должен читать никто, кроме владельца, даже члены группы `shop-dev`.

### 6. `/srv/shop/releases/deploy.sh` — исполняемый скрипт публикации

- **Владелец:** root
- **Группа:** shop-dev
- **Права буквами:** `-rwxr-x---`
- **Права числом:** `750`
- **Почему так:** скрипт запускают только владелец и группа `shop-dev`; остальным он не нужен и не должен быть доступен.

## umask команды

Команда использует:

```bash
umask 0027
```

Расчёт прав новых объектов:

| Тип | Формула | Права | Буквами |
|-----|---------|-------|---------|
| Файл | `666 − 027` | `640` | `rw-r-----` |
| Каталог | `777 − 027` | `750` | `rwxr-x---` |

**Почему так:** маска `0027` убирает все права у остальных (`o=---`) и запись у группы (`g-w`). Новые файлы проекта сразу создаются закрытыми, что соответствует принципу минимальных привилегий.

---

## Где нужен sticky-бит и почему

**Sticky-бит нужен в `/srv/shop/uploads`** — общем каталоге загрузок для разработчиков.

Без sticky-бита любой член группы `shop-dev` мог бы удалить или переименовать **любой** файл в `uploads`, включая чужой. Например, `alex` мог бы удалить `photo.jpg`, загруженный `bella`. Это нарушило бы целостность данных и позволило бы саботировать работу коллеги.

С sticky-битом (`+t`, в правах `3770` → `drwxrws--T`) удалить файл может только:

- его владелец;
- владелец каталога (`root`);
- пользователь с `sudo`.

Права группы `shop-dev` на `uploads` — `rwx`, то есть разработчики кладут файлы и работают с ними, но **удаляют только свои**.

### Где ACL был бы полезен

В `/srv/shop/releases` ACL пригодился бы, если нужно дать **точечный доступ** пользователю, не входящему в `shop-dev` (например, аналитику `chris` на запись конкретного файла отчёта), не меняя права всей группы. В базовой схеме это решается правами `2775` (chris читает как «остальные»), поэтому ACL не обязателен.

| № | Объект | Владелец | Группа | Буквами | Числом | Почему |
|---|--------|----------|--------|---------|--------|--------|
| 1 | /srv/shop/src | root | shop-dev | drwxrws--- | 2770 | код только разработчикам, setgid для наследования группы |
| 2 | /srv/shop/releases | root | shop-dev | drwxrwsr-x | 2775 | публикация разработчикам, чтение всем |
| 3 | /srv/shop/uploads | root | shop-dev | drwxrws--T | 3770 | общий каталог, sticky защищает чужие файлы |
| 4 | /srv/shop/src/app.py | alex | shop-dev | -rw-rw-r-- | 664 | общий код, группа пишет |
| 5 | /srv/shop/src/config.env | alex | shop-dev | -rw------- | 600 | секрет, только владелец |
| 6 | /srv/shop/releases/deploy.sh | root | shop-dev | -rwxr-x--- | 750 | исполняемый скрипт только для команды |

## Уборка

```bash
sudo userdel -r alex
sudo userdel -r bella
sudo userdel -r chris
sudo groupdel shop-dev
sudo rm -rf /srv/shop
rm -rf ~/docs ~/file-umask.txt ~/dir-umask ~/example.txt
```
